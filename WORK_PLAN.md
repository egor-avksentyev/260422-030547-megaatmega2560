# План работ

## 1. Выровнять пункты меню

- Привести все пункты меню к единому и корректному положению.
- Убедиться, что элементы меню не смещаются и не заходят на области **Mute** и **Bypass**.
- Проверить корректность отображения меню во всех состояниях.

## 2. Исправить индикацию Bypass при выключении системы

- При включённом **Bypass** индикатор должен оставаться в соответствующем состоянии.
- Сейчас при выключении системы происходит переключение индикации **с красного на зелёный**, чего быть не должно.
- Исправить логику переключения цвета/состояния индикатора при выключении системы.

## 3. Добавить анимацию для пунктов меню (пока не делать)

- Реализовать анимацию перехода между пунктами меню.
- Сделать анимацию плавной и визуально согласованной с интерфейсом.
- Проверить корректность анимации при переключении между всеми пунктами.

## 4. Выставить Delta вокруг нулевого положения для High

- Выставить **идеальное нулевое положение** как центральную точку диапазона.
- Сделать **Delta в минусовую и плюсовую сторону одинаковой** относительно нуля.
- Сейчас диапазон смещён: в минусовую сторону Delta практически отсутствует, а в плюсовую — значительно больше.
- Необходимо точно отцентрировать диапазон, чтобы отклонение **−Delta = +Delta** относительно идеального нуля.
